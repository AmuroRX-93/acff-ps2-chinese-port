# ACFF v0.12.14 使用说明

这是 PSP 既有民间汉化资源移植至 PS2 的公开测试版，无偿分享。
原 PSP 汉化：becky、ben、WEFGOD 等；PS2 移植发布：AmuroRX-93。完整致谢和原发布地址见同目录 CREDITS.md。

## 只用一个入口

完整解压压缩包。Mac 双击包根目录“开始使用.command”；Windows 双击“开始使用.bat”。
按回车选第一项：整合版启动游戏；差分／升级包开始生成新版镜像。
“工具”是程序文件，无需自己翻找；“说明”是说明和校验信息；整合版的 ISO 在“游戏”文件夹。

Mac 启动整合游戏会自动寻找已安装的 ARMSX2 或 PCSX2。Windows 的启动入口会寻找 PCSX2；找不到时按提示拖入模拟器 exe。也可以直接在自己的 PS2 模拟器里打开“游戏”目录中的 ISO。

Windows 菜单的游戏启动及所有系统的安装、校验、升级功能，需要 Python 3.10+，仅使用标准库。下载：https://www.python.org/downloads/ 。Windows 安装时勾选 Add Python to PATH。Mac 启动整合游戏不要求 Python。

## 旧版用户，最省下载量的方法

已经用过上一公开版 v0.12.6 补丁，或旧镜像整合包：下载“旧版升级包”（约 2.2 MB）。
运行开始使用，直接按回车；选择旧 ISO 或尚未解压的旧整合 ZIP。
无需重新下载原版，无需先解压旧 ZIP。包中的 ISO 必须是公开 v0.12.6，文件名可以改。
工具会校验输入版本、生成新 ISO，再读回检查。新 ISO 默认在旧文件旁边。预留约 3.6 GB 空间。原文件保持不变。

## 原版用户

使用“原版汉化补丁”（约 554 MB），运行开始使用并按回车，选择 PS2 日版 SLPS-25461 原版 ISO。
原版大小：3,470,426,112 字节。
原版 SHA-256：e94c881b242e8614939f39de40e4e0dbd416b3e88c78345dd345a294554d15a9

## 已下载新版整合

直接玩“游戏”文件夹里的新 ISO，不需要打差分。
需要放回旧游戏目录时，在菜单选 2，选择自己的镜像目录；工具复制新镜像并校验，不覆盖旧文件。随后用模拟器打开新镜像，或重新扫描游戏目录。

## 沿用存档

先在旧游戏中保存并退出。用新 ISO 冷启动，从游戏内读取原来的记忆卡存档。
不要读取旧版即时存档，它保存了旧程序和字库；无需重开档，不要覆盖自己的记忆卡。
本包不修改模拟器设置；模拟器、BIOS 和记忆卡沿用自己的安装。

## 命令行

在完整解压的包根目录运行，Windows 可将 python3 换成 py -3。

```sh
python3 工具/installer/manage.py verify
python3 工具/installer/manage.py install "/游戏目录"
python3 工具/installer/manage.py patch "/路径/旧版.iso"
python3 工具/installer/manage.py patch "/路径/旧整合包.zip" --output "/目标目录/ACFF_v0.12.14.iso"
python3 工具/installer/manage.py verify "/路径/新版.iso"
open -a ARMSX2 --args -- "游戏/ACFF_PS2_PSP_Chinese_Port_v0.12.14.iso"
```

Mac 如果提示 .command 无执行权限，在终端运行：bash "开始使用.command"。

# ACFF v0.13.1 校对修订测试版

从 GitHub 公开 v0.13.0 影片版直接生成包含9月22日界面/译文与9月28日校对反馈的新版ISO。保留原有影片，更新ED2/GP1/GP3字幕，恢复“架构师”称呼，补全11组邮件的信息与语气。

## 准备与安装
游戏为PS2 SLPS-25461。本包是升级差分，不是完整游戏，也不是日文原版直升补丁。输入必须是未经后续修改的公开v0.13.0 ISO；完整指纹在manifest.json。9月22日等其他本地中间版不作为输入，请取回原v0.13.0副本。已是最终修订版会提示无需升级。
退出游戏，解压ZIP后双击本平台入口，输入旧ISO路径。输出默认在旧ISO旁，名字增加“_20260928修订.iso”。需要至少3.6GB可用空间。工具保留输入，不覆盖同名输出；失败.partial不会当成成功ISO。

命令：`PY install.py --input "旧版.iso" --output "新版.iso"`
只检查：`PY install.py --input "旧版.iso" --output "新版.iso" --check`
回退：重新打开旧ISO即可；工具不写任何记忆卡或即时存档。新版请冷启动后读游戏内存档。

## 三种使用环境
- PC：在PS2模拟器里打开生成的新ISO，继续用原记忆卡。
- 安卓：电脑生成后传入手机，使用原模拟器打开新ISO。此ZIP的Python脚本不是安卓App；没有电脑时请使用另行提供的新版整合ISO，不能直接把本ZIP复制进游戏文件夹。
- PS2实机：生成新ISO后按现有OPL及USB/SMB/MX4SIO/HDD流程部署；HDD安装不一定是直接复制。此补丁不附带OPL，不承诺所有介质组合已实测。

## 通用操作与排错
完整解压整个ZIP，不能在压缩包里双击脚本。包内已带 Windows x64、macOS Apple Silicon 和 Intel Python，无需另装Python或联网。Windows ARM、Windows7不作兼容承诺。
Windows 双击 Windows安装.bat；Mac 双击 macOS安装.command。按提示输入或拖入路径。不要选压缩包文件，不要修改payload和manifest。
命令行可以把下面的 PY 替换为：
- Windows：runtime\windows-x64\python.exe
- Apple Silicon：./runtime/macos-arm64/python/bin/python3
- Intel Mac：./runtime/macos-x64/python/bin/python3
在解压包目录打开终端。Windows可用PowerShell `& .\runtime\windows-x64\python.exe .\install.py --help`；Mac可用 `./runtime/macos-arm64/python/bin/python3 -E -s -B install.py --help`。Mac若执行位丢失，先 `chmod +x macOS安装.command runtime/macos-*/python/bin/python3*`。
失败时看控制台和安装日志.txt；版本不匹配时保留报出的SHA256，不要强行绕过检查。缺少engine/运行时通常应重新完整解压，不要把单个脚本拖到别处运行。检查不是运行验收。
下载校验：Windows `Get-FileHash -LiteralPath 包名.zip -Algorithm SHA256`，Mac `shasum -a 256 包名.zip`，与SHA256SUMS.txt比较。内置文件清单在 PACKAGE_FILES.json。
